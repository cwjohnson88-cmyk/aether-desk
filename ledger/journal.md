# Aether Desk journal

Paper trading only. Predictions are hypotheses, not advice.

## How to use this file

After each session, append:

- Ideas taken vs skipped
- Hit rate, avg R, max adverse excursion (when trades exist)
- Process errors (late data, bad size, thesis drift)
- One concrete code or process change for next week

Desk Engineer implements only changes that tests cover. Risk limits in
`config/risk.yaml` do not change without an explicit human command.
